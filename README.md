# 레몬하우스 카페 새 글 좋아요·댓글 자동화

레몬하우스 네이버 카페에 올라온 새 글에 **좋아요를 누르고 짧은 댓글을 남기는** 자동화입니다.
ego lite 브라우저로 동작하고, 윈도우 작업 스케줄러가 매일 정해 둔 시간에 실행합니다.

## ⚠️ 먼저 읽으세요 — 최초 1회, 본인 계정으로 직접 로그인해야 합니다

이 자동화는 **ego lite 브라우저에 본인 네이버 계정이 로그인돼 있어야** 동작합니다.

- **로그인은 사용자가 직접 합니다.** 이 도구는 아이디·비밀번호를 입력하지도, 저장하지도 않습니다. 코드·설정 파일 어디에도 비밀번호가 없습니다.
- **최초 1회만** 하면 됩니다. 로그인 화면에서 **"로그인 상태 유지"를 반드시 켜세요.** 켜지 않으면 ego lite를 닫거나 PC를 껐다 켤 때 로그인이 사라져 자동화가 멈춥니다.
- "로그인 상태 유지"로 로그인하면 약 1년간 유지됩니다. 네이버가 보안상 로그인을 풀면 자동화가 멈추고 윈도우 알림이 뜹니다. 그때만 다시 로그인하세요.
- **자기 계정으로 올라갑니다.** 좋아요와 댓글은 로그인한 본인 카페 닉네임으로 등록됩니다. 다른 사람 계정으로 로그인하지 마세요.
- **업무용 다른 계정과 프로필을 나누세요.** 네이버 로그인은 ego lite **프로필 하나에 계정 하나**만 유지됩니다. 같은 프로필에서 다른 계정(예: 블로그 계정)으로 로그인하면 카페 쪽 로그인이 바뀝니다. 아래 설치 순서의 `setup-profile.ps1`이 카페 전용 프로필을 따로 만들어 줍니다.

## 준비물

- Windows 10/11, Windows PowerShell 5.1(기본 포함)
- ego lite 설치 (`ego-browser` 명령이 동작해야 합니다)
- 레몬하우스 카페 회원이며 댓글 권한이 있는 네이버 계정

## 설치 순서 (약 10분)

PowerShell을 열고 이 폴더로 이동한 뒤 순서대로 실행합니다.

1. **카페 전용 프로필을 만들고 로그인 화면 열기**
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup-profile.ps1
   ```
   ego lite 창이 하나 더 열리고 네이버 로그인 화면이 나옵니다. **본인 계정으로 직접 로그인하고 "로그인 상태 유지"를 켜세요.**
2. **카페 닉네임 등록** — 로그인한 계정의 카페 닉네임을 읽어 `config.json`에 저장합니다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\run.ps1 -Mode check
   ```
   `RESULT: REGISTERED` 가 나오면 성공입니다.
3. **미리보기** — 아무것도 올리지 않고 대상 글과 댓글 문구만 보여 줍니다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\run.ps1 -Mode dry
   ```
4. **매일 자동 실행 등록** (기본 17:00, `-Time 18:30`처럼 바꿀 수 있음)
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install-schedule.ps1
   ```

처음 한 글만 직접 올려 보고 싶다면: `.\run.ps1 -Mode one -Article <글번호>`

## 하는 일과 안전장치

- 최근 24시간(PC가 꺼져 있었다면 마지막 실행 이후, 최대 7일) 글만 대상입니다. 내 글과 댓글이 막힌 글은 건너뜁니다.
- 글마다 **좋아요 → 댓글** 순서로 처리하고, **글 사이에 20~30초**를 둡니다.
- **건드리지 않는 글:** 고객 견적·상담 문의글(문의게시판, 비공개 글)에는 좋아요도 댓글도 달지 않습니다. 메뉴 이름에 `문의|상담|견적|A/S`가 들어가거나 비공개 글이면 건너뜁니다. 패턴은 `config.json`의 `skipMenuPattern`으로 바꿀 수 있습니다.
- **중복 방지:** 이미 좋아요를 눌렀으면 다시 누르지 않고, 내 닉네임 댓글이 이미 있으면 댓글을 쓰지 않습니다(화면과 댓글 목록 둘 다 확인). 처리한 글은 `state.json`에 기록해 다시 처리하지 않습니다.
- **댓글 문구:** 글 종류(공사 현장·완공·컬러·영상·후기·이벤트·팁)에 맞는 문구 묶음에서 고르고, 글의 평수·지역·색상을 넣어 매번 조금씩 다르게 씁니다. 최근에 쓴 문구는 다시 쓰지 않습니다. 문구를 바꾸려면 `run.mjs`의 `POOL`을 고치세요.
- **바로 멈추는 경우:** 로그인이 풀림 / 다른 계정으로 로그인됨 / 네이버 보호조치·캡차 안내 / 좋아요·댓글 등록이 확인되지 않음. 멈추면 윈도우 알림이 뜨고 이유가 `last-report.json`에 남습니다. 캡차는 풀지 않습니다.
- 카페의 도배 제한을 넘지 않도록 하루 한 번만 돌리세요. 카페 운영 정책은 사용자 책임입니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| `RESULT: NOT_LOGGED_IN` / 알림 "로그인 필요" | 전용 프로필의 네이버 로그인이 풀렸습니다. `setup-profile.ps1`을 다시 실행해 로그인 화면을 열고 "로그인 상태 유지"를 켜서 로그인하세요. |
| `WRONG_ACCOUNT` | 전용 프로필에 다른 네이버 계정이 로그인돼 있습니다. 올바른 계정으로 다시 로그인하세요. 일부러 계정을 바꾸는 거라면 `config.json`의 `expectNick`을 비우고 `-Mode check`를 다시 실행하세요. |
| `PROFILE_MISSING` | config.json의 프로필이 ego lite에 없습니다. `setup-profile.ps1`을 다시 실행하세요. |
| 매번 로그인이 풀림 | 로그인할 때 "로그인 상태 유지"를 켜지 않았습니다. 켜고 다시 로그인하세요. |
| `BLOCKED: …` | 네이버가 보호조치를 안내했습니다. 그날은 중단하고, 몇 시간 뒤 `-Mode dry`로 확인한 뒤 다시 실행하세요. |
| `COMMENT_CHECK_FAILED` | 댓글 목록을 3번 연속 읽지 못했습니다(네트워크·네이버 점검). 잠시 뒤 다시 실행하세요. 한 글만 읽지 못하면 그 글만 건너뛰고 계속합니다. |
| 실행이 안 되고 "스크립트 실행 정책" 오류 | 위 명령처럼 `powershell -ExecutionPolicy Bypass -File …`로 실행하세요. |

실행 기록은 `runs.log`(요약), `run.log`(상세), `last-report.json`(마지막 결과)에 남습니다.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `setup-profile.ps1` | 최초 설정: 카페 전용 프로필 만들기, 로그인 화면 열기 |
| `run.ps1` | 실행기 (`-Mode apply/dry/one/check`) |
| `run.mjs` | 본체: 대상 글 찾기, 좋아요, 댓글, 중복·계정 확인 |
| `check-login.mjs` | 로그인 계정·카페 닉네임 점검 (읽기 전용) |
| `open-login.mjs` | 전용 프로필에 네이버 로그인 화면 열기 |
| `install-schedule.ps1` | 윈도우 작업 스케줄러에 매일 실행 등록·해제 (`-Remove`) |
| `notify.ps1` | 윈도우 알림 |
| `config.example.json` | 설정 예시. `setup-profile.ps1`이 `config.json`을 만듭니다 |

`config.json`·`state.json`·로그는 개인 정보(닉네임, 처리한 글 목록)라서 `.gitignore`로 저장소에서 제외돼 있습니다. 올리지 마세요.
